# CU After Class — Fall Break Field Guide

A responsive, buildless GitHub Pages site for October 13–18, 2026.

## Publish
Create a public GitHub repository, upload `index.html`, `activities.json` and `.nojekyll` to the root of `main`, then choose Settings → Pages → Deploy from a branch → main → /(root). No build or dependencies required.

## Content
35 activity ideas with official venue/source links, filters, Shiloh shortlist, four suggested outings, local saved favorites, and copy-to-clipboard sharing. Fixed dates and hours were checked October 13, 2026. Unconfirmed claims from the original chat are disclosed on the page. Flexible ideas may require booking or an hours check.

## Update
Activity data is embedded in index.html so the page also works offline. activities.json is a readable data copy; keep both synchronized when editing. No analytics, tracking, accounts, external fonts, or cookies. Favorites stay on the visitor’s device.
